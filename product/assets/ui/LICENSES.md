# Title interface provenance

main_menu_background.png is the original operator-requested image_gen artwork
identified by the PRD main-menu-background-v1 generation record. It was acquired
from the registered local pool into this exact binding; the adjacent acquisition
receipt remains unchanged. The PRD explicitly authorizes this original background
for the title/pause surface. Source game screenshots were style references, not
bundled artwork. Generated-art service terms apply; this file is not asserted to
be CC0 or MIT. The pool receipt retains its original unknown-license label. Project use is
authorized by PRD 6.10 and the original generation provenance, rather than by
that label; no third-party permissive license is invented.

main_menu_icons.svg: original product-authored leaf, compass, book, settings,
exit and old-lamp vector atlas. No commercial screenshot, font glyph or editor
icon was extracted. These icons are part of this game's source.

The textured panels reuse Kenney Fantasy UI Borders (CC0), with subtle native
NoiseTexture2D grain. Menu audio reuses Kenney Interface Sounds (CC0). See the
existing licenses under assets/dialogue. Typography reuses the existing bundled
EB Garamond / Zhuque Fangsong serif and script-fallback chain.
